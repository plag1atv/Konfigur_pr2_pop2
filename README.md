Этот проект предоставляет инструмент для анализа зависимостей пакетов в Alpine Linux (APK). Он позволяет строить граф зависимостей, вычислять порядок загрузки пакетов и проверять наличие циклических зависимостей.
Установка и запуск

1.Клонируйте репозиторий

```
git clone https://github.com/ваш-репозиторий
cd ваш-репозиторий
```

2.Установите зависимости

Для работы приложения потребуется Python 3.x. Установите необходимые зависимости:

```
pip install -r requirements.txt
```

3. Запуск приложения

Запустите программу с помощью следующей команды, указав параметры:

```
python main.py --package-name <название_пакета> --repo <репозиторий_URL_или_путь> --mode <real|test> --version <версия> --output-file <файл_для_вывода> --filter <подстрока_для_фильтрации> --show-load-order
```

Пример использования:

1. Режим теста (с тестовым репозиторием):

```
python main.py --package-name A --repo test_repo.txt --mode test --version 1.0 --output-file graph.json --show-load-order
```

2. Режим реального репозитория (с репозиторием APK):

```
python main.py --package-name busybox --repo https://dl-cdn.alpinelinux.org/alpine/v3.18/main --mode real --version 1.36.1 --output-file graph.json
```

О проекте

Цель проекта:
Анализ зависимостей пакетов в Alpine Linux (APK).
Строительство и визуализация графа зависимостей.
Вычисление порядка загрузки зависимостей с помощью топологической сортировки.
Обнаружение циклов в зависимостях.

Особенности:
Поддержка двух режимов работы:
real — анализ реального репозитория APK.
test — использование тестового репозитория с заранее подготовленными данными.
Фильтрация зависимостей по подстроке.
Обработка циклических зависимостей.
Топологическая сортировка для вычисления порядка загрузки зависимостей.

Как работает:

1. Программа использует рекурсивный обход в глубину (DFS) для построения графа зависимостей.
2. Для каждого пакета определяются его прямые зависимости, а затем строится полный граф.
3. При вычислении порядка загрузки применяется топологическая сортировка, которая обеспечивает, что все зависимости загружаются до самого пакета.
4. Программа поддерживает обнаружение циклических зависимостей и предупреждает пользователя о проблемах в структуре пакетов.

Примеры вывода программы

1. Тест с циклическими зависимостями

Файл `test_repo.txt`:

```
A: B
B: A
```

Запуск:

```
python main.py --package-name A --repo test_repo.txt --mode test --version 1.0 --output-file graph.json --show-load-order
```

Пример вывода:

```
=== Настройки приложения ===
package_name = A
repo = test_repo.txt
mode = test
version = 1.0
output_file = graph.json
filter = 
show_load_order = True
=============================

Построение графа зависимостей...

Граф зависимостей (в формате JSON):
{
    "A": ["B"],
    "B": ["A"]
}

Обнаружен цикл в зависимостях: A

Граф сохранён в файл: graph.json

Порядок загрузки зависимостей:
1. A
```

2. Тест с обычными зависимостями

Файл `test_repo.txt`:

```
A: B C
B: D
C: E
D:
E:
```

Запуск:

```
python main.py --package-name A --repo test_repo.txt --mode test --version 1.0 --output-file graph.json --show-load-order
```

Пример вывода:

```
=== Настройки приложения ===
package_name = A
repo = test_repo.txt
mode = test
version = 1.0
output_file = graph.json
filter = 
show_load_order = True
=============================

Построение графа зависимостей...

Граф зависимостей (в формате JSON):
{
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["E"],
    "D": [],
    "E": []
}

Граф сохранён в файл: graph.json

Порядок загрузки зависимостей:
1. D
2. E
3. B
4. C
5. A
```


Как добавить новые репозитории

1. Для теста:
   Создайте новый текстовый файл с зависимостями, например `test_repo_2.txt`, в том же формате, что и `test_repo.txt`, и укажите путь к этому файлу при запуске программы.

2. Для реального репозитория:
   Укажите URL репозитория Alpine Linux и используйте его для анализа зависимостей пакета.
