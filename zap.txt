Порядок установки для простого случая:
python main.py --package-name A --repo test_repo.txt --mode install-order --version 1.0 --output-file order.txt

Порядок установки с циклической зависимостью:
python main.py --package-name H --repo test_repo.txt --mode install-order --version 1.0 --output-file order_cycle.txt

Сравнение с реальным apk (на реальной системе):
python main.py --package-name curl --repo http://dl-cdn.alpinelinux.org/alpine/latest-stable/main --mode install-order --version 1.0 --output-file curl_order.txt --compare-with-apk

Сложный граф:
python main.py --package-name K --repo test_repo.txt --mode install-order --version 1.0 --output-file complex_order.txt
